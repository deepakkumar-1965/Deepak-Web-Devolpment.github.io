This project contains practical programs based on **HTML, CSS and JavaScript**. Each program is stored as a separate HTML file and can be opened directly in a web browser.

The project includes basic programs, DOM manipulation, events, forms and validation, browser objects, web storage, and JavaScript mini projects.

5. The program will open and can be executed directly in the browser.
